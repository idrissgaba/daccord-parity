## 0. Règles (rappel)

- Un élément n'est ✅ que si la comparaison visuelle (section 5 de la mission) a été faite
  contre une capture de `docs/discord-ref/`. Aucun ✅ n'est posé dans cet audit : aucune
  comparaison côte à côte n'a encore été faite.
- Statuts : ❌ absent · ⚠️ partiel · ✅ identique (vérifié par capture) · 🚫 impossible
  (raison + alternative).
- Priorités : **P0** partage d'écran / Live (friction actuelle) · **P1** disposition, messages,
  vocal · **P2** menus, raccourcis, paramètres, notifications · **P3** confort.
- « à confirmer » = point non couvert par une capture Discord ; il reste tel quel jusqu'à
  capture.
- Interdits : logo/nom/sons/polices/SVG/code Discord. Équivalents libres uniquement.

### 1.1 Captures manquantes (à fournir ou à faire ensemble)

Impossible pour moi sans effet de bord sur votre compte Discord (nécessite un 2ᵉ participant,
un stream réel, ou votre téléphone). Tant qu'elles manquent, les points concernés restent
« à confirmer ».

Desktop (il faut un ami en vocal, ou vous + moi sur votre serveur « Idriss + Ichraq ») :
1. Vue d'appel avec **2+ participants** (grille, anneau vert quand quelqu'un parle, icônes micro/casque sur les tuiles, menu d'un **autre** participant, bande de focus avec plusieurs tuiles). Le 2026-11-04 votre compte Discord était en vocal avec KinGo depuis un autre client : rejoindre un salon depuis le web aurait coupé cet appel, et l'aperçu d'un salon sans le rejoindre n'existe pas sur Discord web — les captures complémentaires prévues (menu « … » de la barre, chevrons micro/caméra, dialogue « Invite to Voice ») restent à prendre quand le compte est libre.
2. ~~Partage d'écran — fenêtre de sélection du client desktop~~ → couvert par les images officielles Discord (`official-share-picker-step1/2`) ; une capture de votre client desktop reste bienvenue pour les détails de thème sombre.
3. ~~Streamer : aperçu de son propre stream + menu~~ → fait le 2026-11-03 (`desktop-stream-own-*`).
4. ~~Liste des salons : badge LIVE + survol~~ → fait (`desktop-stream-live-badge-hover`, `desktop-stream-others-channel-list`, carte d'un autre streamer : `official-watch-stream-card`).
5. Vue d'appel : stream regardé → images officielles (`official-watching-stream-focus`, `official-watched-stream-menu`) ; reste la **tuile de stream non regardé** (bouton Watch Stream dans la grille) et le **compteur de spectateurs** éventuel, qui demandent un second participant.
6. **Deux streams simultanés** (second participant).
7. **Soundboard** ouvert depuis le vocal (grille emoji + nom, recherche, favoris, volume) et indication sur l'avatar de celui qui joue.
8. ~~Mode focus + plein écran + pop-out~~ → fait (`desktop-stream-own-focused`, `-fullscreen`, `-popped-out-main`) ; reste la fonction de l'icône « participants » sur la bande.
9. ~~Réactions, réponse avec aperçu, message épinglé, séparateur « New Messages »~~ → fait le 2026-11-04 (`desktop-message-*`, `desktop-new-messages-bar`). Restent **à confirmer** : la barre « jump to present » (il faut un historique plus long qu'un écran avec des non-lus) et l'indicateur « is typing… » (il faut un second compte qui écrit).
10. ~~Glisser-déposer et chips~~ → chips capturées (`desktop-upload-chips`, `-chip-image`) ; l'overlay « Upload to #channel » ne se rend pas sur un glisser synthétique chez Discord : mesuré dans le DOM (`discord-css-metrics-lot-b.md`).

## 4. 🚫 Impossibilités connues et alternatives retenues

| Point | Raison | Alternative la plus proche |

| Miniature d'aperçu du stream dans la carte « Streaming Now » | Le serveur Accord ne génère pas d'aperçu ; LiveKit n'envoie la vidéo qu'aux abonnés ; et un second rendu d'une piste déjà affichée plante le moteur sur Windows | Carte identique (titre, LIVE, bouton Watch Stream / You're Streaming!) avec l'avatar du streamer sur fond noir à la place de la miniature |

### Décisions du lot F (2026-11-05)

- **Captures Discord** : survols, clics droits et ouverture de dialogues seulement, tous fermés sans enregistrer ; aucun message envoyé, statut et profil inchangés. Ctrl+/ s'ouvre chez Discord par `dispatchEvent` (keyCode 191) ; dans l'app, le clavier synthétique ne déclenche pas les raccourcis Flutter, d'où `&open=shortcuts|switcher` dans le harnais.
- **Widget de menu** : une route maison remplace `showMenu` (sous-menus en cascade sur trois niveaux, clavier, largeur au contenu mesurée avec la police de l'app) ; tous les `PopupMenuButton` deviennent `AccordMenuButton`. Les menus avec ligne widget (curseur de volume, réactions rapides) gardent 222 px.
- **Icônes** : Discord ne met **jamais** d'icône à droite (le tableau F de l'étape 0 se trompait) ; à gauche seulement pour Copy … ID, Pin / Favourites et le menu du nom du serveur.
- **Fonctions propres à Accord** gardées sans équivalent Discord : Leave & Delete Data, Hide Server, Remove Server (connexion), Reorder Channels en tactile. Groupées avant Copy ID.
- **Durées** (choix de l'utilisateur, point 1) : expiration locale persistée qui marche dès maintenant ; la branche serveur `feature/lot-f-expiring-prefs` (commit `532e24e`, migrations SQLite 048 / Postgres 033) ajoute `channel_mutes.muted_until`, la table `notification_settings` (+ `GET/PUT/DELETE /users/@me/notification-settings`, événement `notification_settings.update`) et `expires_at` sur la présence (balayage toutes les 30 s). Le client passera au champ serveur au déploiement, sans double mécanisme visible.
- **Niveaux serveur / catégorie** (point 2) : réels côté client — un salon hérite de sa catégorie, puis de l'espace, puis du `default_notifications` de l'espace (le client ignorait ce champ). Suppress @everyone et Suppress All Role @mentions par espace ; les mentions de rôle notifient désormais, comme chez Discord.
- **Do Not Disturb** coupe les notifications desktop et les sons de message (« You will not receive desktop notifications »).
- **« Message @x »** du popout (point 3) : envoie dans le DM, ferme le popout, ne change pas de vue — à confirmer.
- **Block** (point 4) : `AccordDialog` « Block x? » au libellé à confirmer.
- **Pin Channel to Top, Hide Names, Collapse All** (point 5) : préférences locales. Les salons épinglés s'affichent au-dessus de la liste (hors glisser) ; Hide Names montre les participants en rangée d'avatars ; « Pin » d'une ligne de DM utilise la même préférence.
- **Ordre de la modération** dans le menu membre (Change Nickname · Roles › · Timeout › · Kick · Ban) : à confirmer, faute d'un autre membre sur « Idriss + Ichraq ».
- **Timeout** : sous-menu de durées (60 s … 1 semaine) en attendant la capture du dialogue Discord.
- **Edit Profile** ouvre la page Profil des paramètres ; la modale d'édition (panneau à gauche + aperçu) relève du lot G.
- **Profil complet** : sans Connections (Accord n'expose que les siennes) ni widgets Board / Wishlist ; l'état vide d'Activity garde le titre et le bouton Message, sans la phrase d'humeur de Discord.
- **Quick switcher** : `$` (Game Profiles) et « Learn more » omis ; Previous Channels = historique de la session.
- **Menu de la puce micro / casque** du panneau : liste des périphériques en sous-menu radio puis Voice Settings (non capturé chez Discord, à confirmer).
