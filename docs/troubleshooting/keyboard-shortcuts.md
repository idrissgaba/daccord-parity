# Keyboard Shortcuts

Press **Ctrl+/** (⌘+/ on macOS) anywhere in the app to see the shortcuts in
force. **Settings → Keybinds** lets you add your own: pick an action, press
**Record keybind**, then the keys you want. A recorded keybind wins over the
built-in one when they clash; remove it with the × next to it. The built-in
keybinds listed below can be re-recorded, removed or restored on the same page.

## Navigation and voice

On macOS, read ⌘ for Ctrl and ⌥ for Alt.

| Shortcut | Action |
|----------|--------|
| Ctrl+K | Quick switcher: servers, channels, DMs and people (`@` people, `#` text channels, `!` voice channels, `*` servers); "Find or start a conversation" opens it too |
| Alt+↑ / Alt+↓ | Previous / next channel in the space |
| Alt+Shift+↑ / Alt+Shift+↓ | Previous / next unread channel |
| Ctrl+Shift+Alt+↑ / Ctrl+Shift+Alt+↓ | Previous / next unread channel with a mention |
| Alt+← / Alt+→ | Back / forward in this session's history |
| Ctrl+Alt+↑ / Ctrl+Alt+↓ | Previous / next space in the rail |
| Ctrl+Alt+→ | Toggle between the last server and your DMs |
| Ctrl+Shift+Alt+V | Go to the current call |
| Ctrl+Shift+N | Create or join a server |
| Ctrl+Shift+M | Mute or unmute your microphone |
| Ctrl+Shift+D | Deafen or undeafen |
| Ctrl+Enter / Escape | Answer / decline an incoming call |
| Ctrl+' | Start a call in the open DM |
| Ctrl+Shift+B | Soundboard (in a call) |
| Ctrl+U | Show or hide the member list |
| Ctrl+, | Open settings |
| Ctrl+/ | Show the shortcuts list |
| Ctrl+Shift+H | Help |

## Chat

| Shortcut | Action |
|----------|--------|
| Escape | Mark the channel as read |
| Shift+Escape | Mark the whole server as read |
| Ctrl+Shift+T | Create a private group |
| Ctrl+P | Pinned messages |
| Ctrl+I | Inbox |
| Ctrl+E / Ctrl+G / Ctrl+S | Emoji / GIF / sticker picker |
| Ctrl+Shift+U | Upload a file |
| Ctrl+Shift+L | Copy the channel's link |
| Ctrl+F | Search |
| Any key | Focus the message box |

In the Windows desktop app the mute and deafen chords (built-in or recorded
in Settings › Keybinds) also work while another app has focus, during a call.
Every other shortcut, and all of them on other platforms, needs the Daccord
window focused.

## Messaging

| Shortcut | Action |
|----------|--------|
| Enter | Send message |
| Shift+Enter | New line in message (desktop and web) |
| ↑ (empty composer) | Edit your last message in the channel |
| Escape | Cancel a reply, or close the @mention list |
| Tab / Enter (with the @mention list open) | Insert the highlighted mention; ↑/↓ move the highlight |
| `:` + two letters (`:thu`) | Emoji suggestions; Tab / Enter insert the highlighted one, ↑/↓ move, Escape closes |
| Ctrl+E / Cmd+E | Open the emoji picker |
| Ctrl+B / Ctrl+I / Ctrl+U (with text selected) | Bold / italic / underline the selection |
| Shift + Delete (in the message menu) | Delete without the confirmation |
| Ctrl+V / Cmd+V | Paste image or text from clipboard |

## Editing a Message

| Shortcut | Action |
|----------|--------|
| Enter | Save the edited message |
| Shift+Enter | New line |
| Escape | Cancel the edit |

To start editing, press ↑ in the empty composer, or open the message's context
menu and choose **Edit**.

## Mobile / Touch

On Android and other touch devices, long-press a message to open the context menu (reply, edit, delete, react).
